# BLC_DPC 实现计划与设计讲解（顺序可交换性实验）

> 面向"为什么这么设计"，不是"怎么用"。接口/复现命令/结果表见 [README.md](README.md)。
> 本模块的产出不只是"把两级串起来"，而是**一个把'链路排序'从经验变成数据的受控实验**，
> 而且它的价值有一半来自**预测被证伪后挖出的真原因**。

---

## 一、任务边界

- **做**：BLC 与 DPC 串联（`blc_dpc_top.v`）+ 一个 `SWAP_BD` 参数切顺序 + 两套 golden + 判优指标 + 6 格对比图
- **不做**：不接 Demosaic（M3 已覆盖 BLC 的契约边界）、不做整链（M5.3）

## 二、为什么"能不能换"要先做理论推导

因为**只有先有预测，实验才可能给出"信息"**。如果只跑两种顺序然后看"输出不一样"，
得到的结论是废的（"不一样"是必然的）。所以先推导，把问题变成**可证伪的判据**。

### 2.1 两个算子的性质

| 算子 | 形式 | 性质 |
|---|---|---|
| **BLC** | `B(x)_i = max(x_i − OB[p_i], 0)`，`p_i = (row&1)*2 + (col&1)` | **按相位减常数** + **下钳位**（唯一的非线性） |
| **DPC** | 亮点 `P > nb_max + THR` → 抄 `nb_max`；死点 `P + THR < nb_min` → 抄 `nb_min`；`nb_*` = **同色邻居极值** | `min/max/比较` 都是**等变**运算；但邻居集**跨子相位**（见 §4） |

### 2.2 等变性推导

`min/max/比较` 满足：全体加同一常数 `c`，结果也加同一常数。所以**只要邻域内那个 `c` 是均匀的**：

```
D(x + c_p) = D(x) + c_p          （p 为相位，c_p 为该相位常数）
```

而 BLC 就是 `S_{−OB}`（按相位平移）+ `clamp(·,0)`，于是：

```
B∘D = D∘B   ⟺   clamp(·,0) 与 D 可交换
```

而 `max(·,0)` **只在 `x_i < OB[p_i]`（下溢）时才起作用** —— 正常构造 `raw = clean + OB ≥ OB`，钳位是空的。

**⇒ 预测①：`diff ⊆ U = { i : raw_i < OB[p_i] }`。**

## 三、预测两次被证伪（这是本实验最有价值的部分）

| 层级 | 判据 | 结果 |
|---|---|---|
| **预测①** | `diff ⊆ U`（**自己**下溢） | **证伪 8 个像素** |
| **预测②** | `diff ⊆ reach(U)`（同相位邻居**一跳闭包**） | **仍证伪同一批 8 个** |

**预测②同样被证伪，本身就是关键信息**：若分歧是"一个下溢邻居污染中心判据"这类**传播型**机理，
闭包一定覆盖得住。覆盖不住 ⇒ **漏掉的机理与"相位"本身有关，与传播无关**。

**⇒ 定位手法**：不继续猜，直接打印越界像素的相位分布。结果：

- 越界 8 个**全是 G 相位**（Gr 6 + Gb 2）
- G 相位占全图 **50.0%**，却占差异 **88.0%**（22/25）
- R/B 相位的差异只有 **3 个且全在下溢处** ⇒ 与预测①**完全吻合**（说明预测①在 R/B 上是对的）

## 四、真根因：DPC 的 G 中心跨 Gr/Gb 两个黑电平

DPC 的邻居定义（Python 与 RTL 一致）：

```python
ph in (0, 3)  →  if i % 2 == 0 and j % 2 == 0      # R/B：8 个同色邻居
else          →  if (i % 2) == (j % 2)             # G  ：12 个（8 同子相位 + 4 另一子相位）
```
```verilog
wire is_g = (phase == PH_GR) || (phase == PH_GB);   // RTL 同样把 Gr/Gb 归为"G"
```

⇒ **Gr 中心会拿 Gb 像素做邻居，反之亦然**。算法上正确（Gr/Gb 光谱响应相同），
但本设计的黑电平 **`OB[Gr] = 64 ≠ OB[Gb] = 180`，差 116 LSB**！

⇒ 邻域内"按相位平移"**不均匀**（差 116）⇒ `D(x + c_p) = D(x) + c_p` 对 **G 中心天然失效**，
**与下溢无关**。

### 修正后的可交换性必要条件

```
diff ⊆ { c : S(c) 内 OB 全相同 且 无像素低于自身 OB }
         （S(c) = 像素 c 及其同相位邻居闭包）
```
- **R/B 中心**：邻居全是同色 ⇒ OB 相同 ⇒ **不下溢即位级可交换** ✓
- **G 中心**：邻居集合天然跨 Gr/Gb 两个 OB ⇒ **不可交换** ✓

> 顺带一个自检：**若四通道 OB 恰好都相等，G 中心也满足条件 ⇒ 只要不下溢就完全可交换**。
> 所以"顺序能否交换"**依赖器件参数** —— 结论不能背，必须带参数推。

## 五、工程结论

**BLC 必须在前**，理由有两层，第二层才是硬的：

1. **契约层**（较弱）：BLC 给全链一个"0 = 全黑"的物理锚点；下游 Demosaic/AWB/降噪都假设黑电平已减
2. **量纲层**（较强）：**BLC 是唯一能把 Gr/Gb 拉到同一量纲的操作**。若 DPC 先做：
   - 116 LSB 的 Gr/Gb 黑电平差变成混进缺陷判据的"**假台阶**" ⇒ 判定门限依赖"黑电平减没减"
   - 实测：TP `54→55`、FN `6→5`（换顺序就判出不同结果）⇒ **可维护性风险**，不是可接受差异

**质量上两者几乎等价**：位级差异 25/11536 = **0.22%**（max 190），PSNR 差 **0.38 dB**。
⇒ **这个顺序问题不能用"谁更好"回答，只能用"谁与契约/量纲一致"回答。**

## 六、与"降噪/CCM 顺序实验"的方法论对照

| | 降噪 vs CCM | BLC vs DPC |
|---|---|---|
| 靶子 | 无噪声理想图（PSNR/SSIM） | 光强真值 + **已知缺陷位置**（TP/FP/FN） |
| 主结论 | **有明确胜者**（降噪在前 +1.51 dB） | **没有胜者**（0.22% 差异）⇒ 由契约决定 |
| 可交换性 | 处处不可交换（非线性∘线性） | **分相位**可交换（R/B 可、G 不可） |
| 最值钱的点 | 四类独立证据指向同一结论 | **预测被证伪 → 缩小假设空间 → 定位真因** |

**⇒ 两个实验合起来说明一件事**：链路排序的论证有两种形态 ——
**"质量有差"（用 PSNR 判优）** 与 **"质量无差、但量纲/契约有差"（用不变性与量纲判优）**。
第二种更常见，也更容易被面试官追问，因为不能靠报一个 dB 数糊过去。

## 七、踩坑（详见 README 与 [../面试故事集.md](../面试故事集.md) 故事 4）

1. **指标定义域/定义式错了会得出假结论**：第一版"黑电平残差"报 74.5；
   根因是样本里混进了人为写成 1023 的缺陷像素与下溢像素，且指标该用"输出−真值"而非"输出均值"。修正后恒 **0.00**。
2. **别把研究性预测当成 pass/fail 判据**：预测被证伪时退出码为 1 会被误读成"实验失败"；
   `ok` 只应由独立复算门控。
3. **顶层例化两个不同目录的模块**：`blc_core.v` 在 `BLC/`、`dpc_stage.v` 在 `Bayer_DPC_Demosaic/`，
   `-I` 必须两个都指到。
