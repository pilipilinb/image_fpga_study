# 双边滤波降噪实现计划（BilateralFilter，M4 第一模块）

> 来源：`工程要点.md`（伪代码 + PGA 实现要点）+ 链路契约修订（10bit 线性 RGB 域）。本计划把工程要点的 8bit 时代数字全部按 10bit 重推，并补齐架构决策论证（为什么 10bit、bypass 等延迟旁路）。

## 背景与目标

M4 第一模块（三模块降噪 → CCM → Gamma 逐个做）。**输入 = M3 Demosaic 出的线性 RGB 10bit 简流**（`in_data[29:0]` = {r,g,b} 各 10bit + `in_sof/in_eol` + valid/ready 握手），输出同格式（RGB 域，无 phase 侧带）。

6month 计划 P2 W1 验收对齐：双边 RTL 仿真跑通 · 能讲"为什么保边" · "值域核怎么实现（FPGA 为什么不算 exp）" · "与高斯的资源差异" · **PSNR/SSIM 脚本首建**（逐级对比的地基）。

## 为什么线性 RGB 域全程 10bit（架构论证，先记录再实现）

**全链迟早要做一次 10→8 折算**（VDMA 契约 RGB888 不可省），分歧只在哪一环付这笔损失：

- **方案A（Demosaic 出口就折 8bit）**：降噪加权平均在 8bit 上算（量化①）→ CCM 9 乘法负系数相减，8bit 输入误差被系数放大串到三通道、再量化（②③）→ Gamma 前已累积 2~3 次量化误差。
- **方案B（现行）**：中间级全 10bit（舍入误差小 4 倍），全链只在 **Gamma 出口的 1024×8 LUT** 折一次——LUT 内容软件预生成时直接存 round 后的值，**折算零硬件成本、零偏置**（不用在数据通路上加任何东西），与"感知域才是 8bit 显示域"的分域语义对齐。

**澄清"高 2 位无用"的误解**：RAW10 是 0..1023 满量程，比 8bit 多的是**低 2 位精度**，不是高位空余。我们的验证数据是 8bit 真图 `<<1` 生成的才"用不满"（实际 9bit），真机 OV5640 RAW10 满精度。10bit 的边际成本近零：DSP48 天然 18×25bit，代价只是值域 LUT 深一点（512 项仍 1 个 BRAM）。

## 10bit 参数重推（逐项，RTL 按此锁定）

| 量 | 8bit 版（工程要点） | **10bit 版（本实现）** | 推导 |
|---|---|---|---|
| L1 距离 d | \|ΔR\|+\|ΔG\|+\|ΔB\| ≤ 765 | ≤ **3069** | 3×1023；12bit |
| σ_r | ≈30（对应 σ_n≈6） | **240** | ★**按噪声标定**：σ_r ≈ 1.44×E[d] ≈ 4.9σ_n；本实验 σ_n=48 → 235 → 240。**不能只做位宽等比（×4→120 只适合 σ_n=24）**——实测失配会让 PSNR 反低于高斯 3.5dB |
| CUT | ceil(3.11×30)=94 | **ceil(3.11×240)=747** | d>3.11σ 时 63·exp<0.5，round 后就是 0，零精度损失 |
| 值域 LUT 深度 | 95 项→取 128 | **1024**（10bit 地址） | 需 ≥748 项；仍 1 个 BRAM |
| LUT 位宽 | 6bit（0..63） | 6bit 不变 | round(63·exp(−d²/2σ²))，权重 1.0 → 63 |
| den 范围 | [252,1008] | [252,1008] **不变** | spatial Σ=16 × wr≤63；下界 = 中心项 4×63=252 恒存在 → `addr = den−252` 与 8bit 版同构 |
| 倒数 ROM | 1024×13bit，round(2^20/(addr+252)) | 同左不变 | 2^20/252≈4165<2^13 ✓ |
| num 上界 | 18bit | **21bit** | num ≤ den×1023 ≈ 1008×1023 ≈ 2^20 |
| 乘法位宽 | 18×13=30bit，+2^19 round，>>20 | **结果 30bit 已证明**：num≤den×1023 ⇒ num×inv ≤ 1023·2^20 + round 余量 < 2^30；Verilog 乘积 21×13=34bit 全宽，**显式取 [29:20] 为 10bit 结果**（+2^19 后仍在 30bit 内，注释附上界证明）；>>20 后天然 ≤1023，饱和 1023 保留作防御 |
| 空间核 | [1 2 1;2 4 2;1 2 1] 移位 | 不变 | 0 乘法器 |

> **实测结论（3×3 窗口 + 窄空间核）**：双边 32.03dB / SSIM 0.9039，高斯 32.74dB / 0.9216，边缘区 SSIM 双边 **0.9464** > 高斯 0.9453 —— 双边"用少量平坦区降噪能力换边缘保真"的固有取舍；优势随窗口增大而显著（5×5/7×7 才拉开），3×3 是硬件效率的标准选择。

## 架构与流水

```
in(30bit 简流) → line_buffer_fifo_nxn #(.DW(30), .N(3))   ← 30bit 打包为一个"像素"进行缓存
                   │ win_flat = 9×30 = 270bit
                   ▼
              denoise_bilateral_core
                   │  T0: d 计算（组合）：3×|Δ| + 2×add，d 12bit
                   │      ★LUT 地址保护：d 12bit > 地址 9bit，wr = (d>CUT)?0:LUT[d]
                   │        的 mux 必须在地址进 BRAM 之前（越界读防护）
                   │  T1: 值域 LUT 同步读出 wr        ★9 点窗口同拍打 1 拍（对齐点1）
                   │  T2: w = spatial(移位)×wr；9 组 numR/G/B + den 累加寄存
                   │  T3: 倒数 ROM 同步读出 inv        ★num 三路同拍打 1 拍（对齐点2）
                   │  T4: 乘 inv + round(+2^19) + >>20 取[29:20] + 饱和（组合）→ 输出寄存
                   ▼
out(30bit 简流，LAT = 4 拍恒定；bypass 链按 4 拍打，TB 实测后写入文档)
```

- **反压/冻结**：行缓存 `out_ready = !ostall`；核内部**所有流水寄存器统一 `enable = !ostall`**（全局冻结模式——上游行缓存同步冻结、输入不动，stall 期间整条流水原地保持，恢复无缝）。核输出寄存器即 stage 输出（M3 hold_in 模式同构）。
- **sof/eol 透传**：随对齐链逐级打拍，与数据同拍出（RGB 域不需要 phase）。
- 资源预估：值域 LUT 512×6 + 倒数 ROM 1024×13（各 1 个 BRAM）+ 3 个 DSP 乘法（num×inv 可 3 通道复用 1 个 DSP 分时，或 3 个直铺——实现时按时序定，面试点）。

## bypass 等延迟旁路（M4 三模块统一接口，强制）

```verilog
input wire bypass,   // 1 = 旁路：in_data 直通 out_data（等延迟），语义 = "关闭本模块算法"
```

- **实现**：处理路径 LAT=4 拍 → bypass 路径的数据+sof/eol 打**相同 4 拍**的寄存链 → 出口 mux。等延迟是命门：不等则 bypass 切换时侧带错位、行场结构破坏
- **切换时序**：bypass 为帧级配置，**在 sof 边界切换**（TB 隔帧切，不在帧中间切）；出口 mux 组合实现
- **验证**：TB 增加 bypass 场景——`bypass=1` 时输出与输入**位级全等 + 延迟拍数不变**（双向切换各测一次）。
- **场景价值（写进文档的面试故事）**：半导体检测要"关 CCM 和降噪、检测后单独走显示通路"——检测算法需要未经色彩校正的确定性灰度响应；bypass 是算法边界的产品化表达，不只是调试开关。呼应全局 README 集成设计约束的"bypass 位"。

## 验证计划

1. **数据**：M3 Python 链（BLC→DPC→bilinear demosaic）输出 10bit RGB → 注入高斯噪声 → `denoise_in.hex`；期望 = Python 双边**位级同构**复算（LUT 表生成、倒数 ROM 表生成、round/移位/饱和全部按 RTL 定点公式）——系数文件与 golden 同源生成，天然消除浮点 vs 定点的不一致风险
2. **TB**：仿 M3 协议 TB 四场景（满速/汇随机/长拉低/双向随机）+ IMG 模式 + **bypass 场景**（隔帧切换）
3. **指标**：PSNR + **SSIM 首建**（按 luma = 0.299R+0.587G+0.114B 折算灰度计算；skimage 可用则用，否则手写）；对比实验 = 同噪声下 **Python 高斯参考**（同 10bit 域、同 [1 2 1;2 4 2;1 2 1]/16 核——历史 GaussianFilter 是 8bit Bayer 单通道版不直接可复用，且对比对象是算法效果非 RTL）vs 双边（保边证据：边缘区 SSIM/PSNR 分项）

## 边界与范围

- **验证范围**：M4 为单模块独立验证（输入 = 预生成的 M3 链输出数据）；与 M3 top 的 RTL 级联合验证放 M5 整链串联
- **σ_r 可配性**：仿真版 LUT/倒数 ROM 为静态表（`$readmemh`，宏或参数选 1~2 套 σ_r 档位）；AXI-Lite 动态写表（σ_r 随噪声档位/增益重生成）留集成阶段——表内容与地址映射不变，只换内容，硬件无改动

## 面试点清单

1. **为什么保边**：值域核让"与中心差得远的邻居"权重→0——边缘两侧互不污染，高斯（纯空间核）会糊边
2. **FPGA 为什么不算 exp**：值域核查 LUT（6bit 权重）+ 3.11σ 截断（88% 表项是浪费，截断后 512 项 1 个 BRAM）
3. **倒数 ROM 技巧**：归一化除法 → 查 round(2^20/den) 表 + 1 次乘法；一次除法三通道共用（den 只开一个）
4. **对齐两坑**：LUT 同步读 1 拍（d 与窗口同拍打）、倒数 ROM 同步读 1 拍（num 三路同拍打）
5. **与高斯的资源差异**：多一个 LUT + 倒数 ROM + 3 个乘法 vs 纯加法树；换来看保边
6. **为什么 10bit**：多级链量化累积 vs 单次折算；Gamma LUT 预存 round 值零成本无偏置
7. **bypass 与算法边界**：半导体检测关 CCM/降噪的场景，等延迟旁路的工程实现
