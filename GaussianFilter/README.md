## 项目简介

高斯滤波 = 用"**中间权重最大、越远越小**"的加权核做卷积，平滑噪声的同时**比均值滤波更保边缘**（中心像素权重高，输出更接近自己）。核：

```
[1 2 1]
[2 4 2]
[1 2 1]    ÷ 16（归一化）
```

本工程工程化要点：

- **系数总和 = 16 = 2⁴** → 归一化就是右移 4 位
- **系数 1/2/4 全是 2 的幂** → 对称分组 + 移位加权，**0 个乘法器、0 个 DSP48**
- 完全复用 MeanFilter 架构（行缓存 + 3×8bit 核），行缓存零改动

## 数学基础：高斯核系数怎么来的（本次核心）

### 一维采样 → [1,2,1]

一维高斯函数：`G(x) = exp(-x² / 2σ²)`（忽略归一化常数，后面统一归一化）。取窗口 x = -1, 0, 1 三个点采样：

| 口径 | σ | 采样值 | 比例 |
|---|---|---|---|
| **精确版** | σ=0.849（由比例反推） | {0.5, 1, 0.5} | 1 : 2 : 1（×2 整数化） |
| 习惯版 | σ≈1 | {0.607, 1, 0.607} | 1 : 1.65 : 1 → 舍入近似 1 : 2 : 1 |

**精确版推导**：要让比例恰为 1:2:1，需要边缘/中心 = 1/2：

```
exp(-1/(2σ²)) = 1/2
→ 1/(2σ²) = ln2
→ σ² = 1/(2·ln2) = 0.7213
→ σ = 0.849
```

即 **[1,2,1] 是 σ=0.849 的离散高斯采样整数化**；"σ≈1"是习惯称法（0.607≈0.5 的近似）。面试时两个口径都要能讲，别把"σ=1 精确导出"说死。

### 可分离 → 外积得到 3×3 核

二维高斯可分离：`exp(-(x²+y²)/2σ²) = G(x)·G(y)`，所以**二维核 = 一维核的外积**：

```
[1,2,1]ᵀ × [1,2,1] =
  [1×1  1×2  1×1]   [1 2 1]
  [2×1  2×2  2×1] = [2 4 2]
  [1×1  1×2  1×1]   [1 2 1]
```

**可分离性也是性能点**：大高斯核（如 5×5）可以先做行卷积再做列卷积，乘法从 N² 降为 2N——本工程窗口 3×3 未走分离，留给大核升级。

### 归一化 → 除以 16 就是右移 4 位

核总和 = 1+2+1+2+4+2+1+2+1 = **16 = 2⁴**。归一化（权重和 = 1）就是右移 4 位——2 的幂的福利。这也保证**纯色区域输出 = 原值**（均值不变性，TB 有专门用例）。

## 为什么 0 个乘法器（对比 pre-adder）

| 路线 | 思路 | 乘法器数 |
|---|---|---|
| 教材原始 | 9 像素 × 9 系数（乘累加） | 9 |
| 教材 pre-adder | 对称合并对称位置的像素 + 系数乘（(A+B)×C） | 4 |
| **本工程** | 对称合并 + **系数 1/2/4 直接移位** | **0** |

```
角组（系数 1）= w11+w13+w31+w33        不乘
边组（系数 2）= w12+w21+w23+w32        左移 1 位
中心（系数 4）= w22                     左移 2 位
加权和 = 角组 + (边组<<1) + (中心<<2)，再 (加权和+8)>>4 归一化
```

- 对称合并（pre-adder 的思想）我们有：**角/边/中心各算一个组和**
- pre-adder 的价值是"把 9 乘法减成 4 乘法"；本核系数是 2 的幂，**那 4 个乘法也变成移位**——pre-adder 的用武之地在任意系数对称核（如 Sobel [-1 0 1;-2 0 2;-1 0 1]）
- 加法树 + 布线 = 0 DSP48，综合器看到这种代码形态本来也会把乘常数优化成移位

## 架构与流水

```
din[23:0]/din_valid ──► line_buffer_3x3（DW=24，crop）──► w11..w33（24bit）
                          ├─ R[23:16] → gaussian_3x3_8b（R 核）
                          ├─ G[15:8]  → gaussian_3x3_8b（G 核）
                          └─ B[7:0]   → gaussian_3x3_8b（B 核）
                          │ 同一 matrix_valid 驱动三核 → o_r/o_g/o_b + o_valid
```

流水 3 级（valid 链 LAT=3 严格对齐）：
```
级1：角组和(10bit) | 边组和(10bit) | 中心(8bit 直取)     ← 4 输入加法树 ×2
级2：加权和 = 角 + (边<<1) + (中心<<2)  → 12bit          ← 移位布线 + 12bit 加法
级3：(加权和 + 8) >> 4，饱和 255                        ← 舍入 + 归一化
```

位宽推导（实现前算好）：角/边组 4×255=1020(10bit)；加权和 4080(12bit)；+8 后 4088<4096 不溢出；>>4=255 恰好满值。

## 面试要点

### 1. 高斯核系数推导（本次核心，四步讲完）

"一维高斯采样（σ=0.849 精确导出 1:2:1，σ≈1 是习惯近似）→ 可分离外积得到 3×3 核 → 核总和 16 → 归一化就是右移 4 位。"

### 2. 为什么 0 个乘法器

"系数 1/2/4 是 2 的幂：对称合并后角组不乘、边组左移 1、中心左移 2——教材的 9 乘法器 → pre-adder 4 乘法器在我这里退化到 0。pre-adder 的真正价值在任意系数对称核（Sobel）上。"

### 3. 舍入与变暗陷阱

">>4 截断会有 ≤0.94 LSB 且系统性变暗，先加 8 四舍五入（(sum+8)>>4），误差上界 0.5 LSB——实测恰好 0.5。"

### 4. 可分离性是后续大招

"高斯核可分离成两次一维卷积，大核时乘法从 N² 降 2N——3×3 窗口小没走，5×5 起就该走。"

## 已知限制与后续

- **crop 边界**：输出 (H-2)×(W-2)，边缘一圈缺失；需要全尺寸时照 MeanFilter 的方式换 pad 版行缓存
- **σ 固定**：本核对应 σ≈0.849 的 [1 2 1;2 4 2;1 2 1]；换 σ 需重推核并保证总和为 2 的幂（否则归一化不能纯移位）
- **3×3 未走可分离**：大核升级路径 = 行卷积 + 列卷积（乘法 N² → 2N）
- **后续（W4 周三/中值站已完成，Sobel 待办）**：中值滤波已实现——椒盐场景线性滤波被碾压（中值 26.18dB vs 本工程 20.44dB），详见 [MedianFilter/README.md](../MedianFilter/README.md)；Sobel 边缘检测（任意系数对称核，届时 pre-adder/DSP48 才真正上场）；已与 MeanFilter、MedianFilter 完成工程互链
