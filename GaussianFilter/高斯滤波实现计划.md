# 高斯滤波实现计划（GaussianFilter，W4 第二站）

## 背景与目标

W4 计划（fpga-image-month1-plan.md）："理解高斯核 [1 2 1; 2 4 2; 1 2 1] 的对称性，以及对称核可以用 pre-adder 省乘法器；先用 9 个乘法器跑通，再优化到 4 个"。基于已验证的 `line_buffer_3x3.v`（crop 版，与用户 attached 一致）实现高斯滤波，**重点：把高斯核系数的推导完整讲清楚**（本次学习的核心），并实现"对称分组 + 移位"的最优结构。

**关键洞察（将写入注释与 README）**：高斯核系数总和 = 16（2 的幂）→ 归一化就是 >>4；系数 1/2/4 全是 2 的幂 → 对称分组后加权全部用移位，**0 个乘法器**——比计划里"9 乘法器 → pre-adder 4 乘法器"更优（pre-adder 的价值要在非 2 幂对称核上才体现）。这个落差正是面试亮点。

## 高斯核系数推导（本次核心内容，README 详细展开）

1. **一维高斯采样**：G(x) = exp(-x²/(2σ²))（σ≈1），取 x = -1, 0, 1 → 0.607, 1, 0.607，比例约 1:1.65:1，整数化近似 **1:2:1**
   - 严谨版：比例 1:2 对应 exp(0.5/σ²)=2 → σ=0.849（因此 [1,2,1] 常被称为"σ≈1 的离散高斯"）
2. **可分离性 → 外积**：二维高斯 = 一维高斯 ⊗ 一维高斯
   [1,2,1]ᵀ × [1,2,1] = [[1,2,1],[2,4,2],[1,2,1]]（中心=2×2，角=1×1，边心=2×1）
3. **归一化**：核总和 = 1+2+1+2+4+2+1+2+1 = **16 = 2⁴** → 除以 16 就是右移 4 位（2 的幂的福利）
4. **对称分组（pre-adder 思想）**：角组（系数 1）、边心组（系数 2）、中心（系数 4）：
   sum = (w11+w13+w31+w33) + (w12+w21+w23+w32)<<1 + w22<<2，再 >>4

## 关键决策

1. **行缓存**：line_buffer_3x3.v（crop 版，用户指定）；pad 版留作后续（MeanFilter 已演示变体做法）
2. **核实现**：对称分组 + 移位加权（0 乘法器）；不做"9 乘法器对照版"（学习聚焦最优解，README 讲演变逻辑即可）
3. **通道**：RGB888 三通道并行（1×DW=24 行缓存 + 3×8bit 核），与 MeanFilter 一致
4. **验证**：定点参考全等 + 浮点真高斯核归一化误差统计（≤1 LSB）+ 高斯去噪对比实验（与 MeanFilter 的均值滤波 PSNR 对照）

## 位宽推导（写死）

```
角组：4×255 = 1020 < 2^10 → 10bit
边组：4×255 = 1020 < 2^10 → 10bit
加权和：1020 + 1020<<1 + 255<<2 = 1020+2040+1020 = 4080 < 2^12 → 12bit
>>4 → 9bit（4080>>4 = 255 恰好满值），饱和防御
流水：级1 三组求和 → 级2 移位加权和 → 级3 >>4+饱和；valid 链 LAT=3（吸取 v4 教训：级数必须与 LAT 严格一致）
```

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 浮点真高斯核（1/16 归一化）与整型核误差可能 >1 LSB | 误差理论上界 0.5 LSB（/16 精确）；TB 浮点统计兜底 |
| 分组求和次序导致进位差异 | 三组位宽按最坏推导（10/12bit），全等比对暴露任何截断 |
| 流水级数与 LAT 错位（v4 教训） | 核内 3 级与 valid 链 LAT=3 一一对应，头部注释明示级数 |
| pre-adder 移位实现误解 | README 讲清"9→4→0 乘法器"演变：2 的幂系数直接移位，pre-adder 是非 2 幂核才需要的 DSP 用法 |
