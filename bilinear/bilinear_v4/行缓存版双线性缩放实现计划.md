# 行缓存版双线性缩放实现计划（bilinear_v4）

> 目标：用 3 行环形缓冲 + 行就绪/反压替代 v3 的 4 份整图 ROM，支持流式像素输入（大图/实时视频升级路径）
> 复用：coord_gen.v、bilinear_interp_8b.v、钳位/权重清零逻辑、verify_scale.py 等验证链（零改动）
> 原理图解：本目录 `line_buffer_principle.html`（浏览器打开）

## 背景与目标

v3（bilinear_rgb_top.v）用 4 份整图 ROM 随机读，简单但存储随图像尺寸线性膨胀（1920×1080 需约 5500 块 BRAM，直接爆）。本版只存 3 行、流式输入（din/din_valid），支持大图/实时视频升级路径，复用现有全部数据通路与验证脚本。

范围：学习实现（行宽 112 用寄存器数组/分布式 RAM），可综合、可验证；大图 BRAM 化作为注释升级路径。缩放能力与 v3 一致（放大/缩小整数倍）。

## 架构（行缓存版数据流）

```
din[23:0]/din_valid（流式，光栅顺序输入）
  │  wr_ready（写反压）
  ▼
line_cache2.v（3 行环形缓冲）
  写侧：光栅顺序写当前行，行写完推进
  读侧：按 coord_gen 源坐标 (sy, sx) 随机读 2×2 邻域
  │  rd_ready（行就绪反压）
  ▼
邻居取数 + 钳位 + 权重清零（从 v3 顶层复制，逻辑不变）
  │
  ▼
3×bilinear_interp_8b（复用）──► o_r/o_g/o_b + o_valid + o_done
```

coord_gen 复用：`pixel_en` 由读侧反压（rd_ready）门控——行未就绪时 coord_gen 累加器暂停（现有实现已支持 pixel_en=0 不推进）。

## 核心机制：3 行环形 + 行就绪 + 反压

**存储**：`reg [23:0] line[0:2][0:IN_WIDTH-1]`（3 行，源行 r 存槽位 r%3；分布式 RAM，多读口自由组合）

**两个游标**：
- 写侧：正在写行 `w`（写完 0..w-1），行写完 w+1
- 读侧：coord_gen 输出窗口 `{sy, sy+1}`（sy 单调不减，光栅输出顺序）

**反压判定（核心规则）**：
```verilog
// 读侧就绪：窗口顶行 sy+1 已写完（写领先读 ≤1，则两行都就绪）
assign rd_ready = (sy01 < w);   // sy01 = min(sy+1, IN_H-1)
// 写侧就绪：写侧最多领先读窗口顶行 1 行（3 行环形 + 该规则天然无槽位冲突）
assign wr_ready = (w <= sy01) && (w < IN_HEIGHT);
```
- **放大（写快读慢）**：写侧写到 `w == sy01` 后暂停，等读侧 sy 滑动释放槽位
- **缩小（写慢读快）**：读侧等 `sy01` 行写完（rd_ready 拉低，coord_gen 暂停）
- 谁落后谁等待，统一由上述两判定式协调

**帧控制**：
- 帧启：首帧前 2 行写入期间读侧等待（rd_ready=0），第 2 行写完开始输出
- 帧末排空：输入写完 IN_W×IN_H 像素后写侧停止（wr_ready=0），读侧继续读最后两行直到输出 OUT_TOTAL 像素（o_done 由 coord_gen 产生）

## 核心模块设计

### line_cache2.v —— 3 行环形缓冲
- 参数：`DW=24, IN_WIDTH, IN_HEIGHT`
- 写口：`din, din_valid, wr_ready`（wr_col 计数，满行推进 w）
- 读口：`rd_sy, rd_sx, rd_ready`，输出 4 邻居 `dout00/10/01/11`（组合读，与坐标同拍）
- 内部钳位：sx/sy 及 +1 越界钳位（与 v3 地址钳位一致）；行就绪 `rd_ready = (sy01 < w)`
- 组合读 = 分布式 RAM（多读口免费）；大图升级路径 = 每行换 BRAM（1W2R 需双块或分拍读），行就绪/释放逻辑不变

### bilinear_lb_top.v —— 行缓存版顶层
- 复用：coord_gen（`pixel_en = rd_ready`）、3×bilinear_interp_8b、钳位/越界权重清零
- 替换：4×image_rom → line_cache2 + 邻居钳位取数
- 参数：`IN_WIDTH/IN_HEIGHT/SCALE_N/SCALE_D/FRAC_BITS`（与 v3 一致）
- 端口：`din[23:0]/din_valid/in_ready → o_r/o_g/o_b/o_valid/o_done`
- include 链：头部 include coord_gen.v / bilinear_interp_8b.v / line_cache2.v
- **与 v3 顶层的时序差异**：line_cache2 组合读（0 拍潜伏），u/v/valid0/dout 同拍，无需 v3 的"对齐寄存 1 拍"（那是 ROM 同步读潜伏造成的）

### tb_bilinear_lb.v —— 流式输入自检 TB
- 激励：从 input.hex 逐像素喂 din（din_valid=1），每行随机插 2~3 个气泡（din_valid 周期拉低）验证反压/行就绪
- 参考模型：复用 v3 TB 的 ref_pix（坐标映射一致，钳位/权重清零语义一致）
- 输出：o_valid 时 $fwrite 写 output.coe（与 v3 同格式）
- 铁律：include 被测模块、VCD、`[PASS]/[FAIL]`、超时兜底、控制信号 negedge 置位
- 配置开关：-DSMALL 小图 / -DSCALE3 / -DDOWN2（与 v3 TB 一致）

| 用例 | 配置 | 预期 | 验收标准 |

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 反压死锁（写等读、读等写互等） | 3 行环形 + "写最多领先读 1 行"规则保证至少 2 个空闲槽；TB 超时兜底 + 气泡用例压力验证 |
| 初始前 2 行读侧空等（无输出） | 正常行为（rd_ready=0），TB 不误报 |
| 帧末排空（输入停输出未停） | 写侧 IN_H 行写完后 wr_ready=0，读侧继续到 OUT_TOTAL 像素 |
| 分布式 RAM 行宽大时寄存器爆炸 | 学习宽 112 可接受；注释指明大图换 BRAM（每行 1W2R 双块或分拍） |
| sy+1 越界钳位后行就绪判定 | 钳位后 sy01=sy，rd_ready 只需该行写完（与钳位逻辑一致） |

## 被否决的替代方案

1. **每行 2 块 BRAM（1W2R 并行读 sx/sx+1）**：学习版用分布式 RAM 更简单（多读口免费）；BRAM 化留作大图升级注释，不在本版实现
2. **沿用 line_buffer_3x3 的"延迟链"思路**：那是光栅同步读（延迟 N 行），缩放的源坐标是随机跳变，不适用；本版用环形 + 行就绪
3. **4 行环形**：3 行足够（写 1 + 读 2），4 行冗余
4. **改造 v3 顶层而非新增变体**：两版各存其优（v3 简单、v4 可扩展），学习工程"版本变体并存"惯例，不覆盖旧版
