# bilinear_v3：双线性插值图像缩放实现计划

> 阶段：W3（双线性插值缩放）　目标：RGB888 输入输出，**任意整数倍缩放（放大 N 倍 / 缩小 N 倍）**，可验证闭环
> 参考：`bilinear_v2/coord_gen.v`（坐标生成）、`bilinear_v2/case1_calculate.v`（插值核）

## 范围说明（本版：整数倍缩放，放大与缩小）

- 本版支持**整数倍缩放**：放大 N 倍（`OUT = IN × N`）与缩小 N 倍（`OUT = IN / N`，非整除截断取整）。
- **非整数倍（N/M 比例）参数化已支持但未专项验证**，留待后续版本。
- 缩小场景无需额外机制：源坐标步进 `STEP > 1<<FB`（跳读），ROM 随机读 + 地址钳位天然支持；无行缓存切换问题（这正是选 ROM 的红利）。
- 验证顺序：放大 2 倍 → 放大 3 倍 → 缩小 1/2 → 缩小 1/3（非 2 幂的 STEP 舍入与跳读覆盖）。

## 本版修订记录（基于代码审查）

相对上一版，本版修复了审查发现的硬伤与集成坑，并收敛范围：

1. **位宽公式修正**：权重是"两个 (FB+1) 位相乘"，非单个 (FB+1) 位（原公式照写会截断乘积）。
2. **valid 链 LAT 修正**：case1 数据通路实为 **9 级**寄存器（Stage7 拆 3 级），LAT 应为 **9** 而非 8。
3. **饱和/舍入修正**：case1 饱和判断是死代码、舍入 +1 有 8 位回绕溢出，本版给出 9 位防回绕写法。
4. **补齐"输出 COE → 显示图像"渲染脚本**（需求 2 最后一公里）。
5. **PSNR 参考输入改用 input.coe**（与 ROM 比特同源，消除 JPEG 解码差异与第三方依赖）。
6. **补 ROM 地址位宽/DEPTH 定义**、`sy*IN_W` 操作数扩展防截断。
7. **FRAC_BITS 与核位宽绑定**：W3 冻结 FB=8，"参数化"标为后续 TODO。
8. **边缘钳位与权重清零耦合**，并明确 blinear.m 边界带不作为逐像素 golden。
9. **新增 W4 衔接决策**（顶层预留流式 i_mode）与 **AGENTS.md 修订记录**动作。
10. **范围收敛**：初版移除缩小验证（Step 10 改整数倍扩展）。
11. **范围扩展（实施后修订）**：缩小验证通过（1/2、1/3 均全像素比对 + PSNR>59dB），参数从 SCALE 改为 SCALE_N/SCALE_D（OUT = IN×N/D），RTL 数据通路零改动——coord_gen 的 STEP 公式与 ROM 随机读天然支持 OUT<IN。

## 摘要

学习场景选用**整图 ROM 随机读**而非行缓存：`line_buffer_nxn.v` 只支持光栅顺序读（窗口锚定当前输入像素），而缩放需要任意源坐标 (sx,sy) 的 2×2 邻域；ROM 随机读 + 地址钳位天然支持整数倍放大。行缓存留给 W4 卷积复用。坐标生成用 `coord_gen.v` 的定点累加法（STEP 为 localparam），插值核用 `case1_calculate.v` 的流水算法（**修正其 valid 链错位、饱和死代码、舍入回绕三处**）。

## 不借用 FPGA IP 的可行性确认（已验证，无阻碍）

全部用**纯 RTL 推断**实现，无任何 IP 依赖：

| 组件 | IP 替代物 | 纯 RTL 做法 | 本工程先例 |
|---|---|---|---|
| 存原图的 BRAM | Block Memory Generator IP | `(* ram_style="block" *)` reg 数组 + `$readmemh` 初始化 → 推断 ROM | `line_buffer_3x3.v` 已用 `ram_style="block"` 推断 BRAM 并仿真通过 |
| 乘法器 | mult_9_9 / mult_18_8 IP | Verilog 内置 `*` → 综合器推断 DSP48/LUT | `case1_calculate.v` 注释已给出内置 `*` 替代方案 |

**"COE → BRAM 初始值"环节的替代**（对应 CSDN 链接作者的做法）：
- 作者流程：COE → BRAM IP 的 init 参数
- 本方案流程：COE →(转换脚本去 header/逗号)→ input.hex → `$readmemh` 读入推断 ROM
- **能仿真**：iverilog 原生支持 `$readmemh`，工程已有先例（`tb_rgb_to_ycbcr.v` 用 `$readmemb` 读测试向量）
- **能综合**：Vivado 支持 `$readmemh` 初始化推断 BRAM，自动映射 BRAM 原语且不绑定厂商 IP
- **输出 COE → 图像**：纯文本文件 reshape 即可（verify_scale.py 内置渲染，或 MATLAB fscanf），见下方验证链

## 关键决策（已定）

1. **架构**：coord_gen（坐标+权重）→ 邻居地址钳位 → 4×image_rom 并联（1 拍读齐 4 邻域）→ 3×bilinear_interp_8b（R/G/B 各一）→ RGB888 输出。每拍出 1 像素，满流水。
2. **整数倍缩放**：IN_WIDTH/IN_HEIGHT/SCALE_N/SCALE_D 参数化，`OUT = IN × SCALE_N / SCALE_D`（放大 N 倍 = N/1，缩小 N 倍 = 1/N），STEP_X/Y 为 localparam 累加。验证顺序：放大 2 倍 → 3 倍 → 缩小 1/2 → 1/3。
3. **坐标系**：简单映射 src = dst × (IN/OUT)（累加器版），**无 +0.5 中心对齐**——与 `bilinear_v1/matlab/blinear.m`（L28-41）及 coord_gen.v 的**内部像素公式**一致。**注意**：blinear.m 的边界带处理有缺陷（写入 output_img(1,j)/(i,1) 而非当前位置），**边界带不作为逐像素 golden**（见决策 6）。
4. **定点（位宽公式已修正）**：FB=FRAC_BITS，W3 冻结 **FB=8**。位宽链一般式：
   - u、v：FB 位；1-u、1-v：FB+1 位（u=0 时 1-u=2^FB 需第 FB+1 位）
   - **权重 w=(1-u)(1-v)：2(FB+1) = 2FB+2 位**（FB=8 时 18 位）
   - **权重×像素：2FB+10 位**（FB=8 时 26 位）
   - **四项和：2FB+10 位，+1 进位保护 = 2FB+11 位**（FB=8 时 27 位）
   - 右移 **2FB** 位，舍入位取 `[2FB-1]`，饱和 255
   - **修正 coord_gen 取高 8 位丢精度**：权重取小数低 FB 位 `x_accum[FB-1:0]`。
5. **乘法器**：Verilog 内置 `*`（综合器推断 DSP48），不例化 IP。
6. **边缘（钳位 + 权重清零耦合）**：src_int 与 src_int+1 超出 [0, IN-1] 时钳位到边界，**同时被钳位方向的权重清零**（`if(sx==IN_W-1) u_frac=0; if(sy==IN_H-1) v_frac=0;`），保证钳位侧退化为最近邻、不产生错值。RTL 采用纯钳位语义（自洽、视觉更优），**TB/PSNR 参考模型按钳位语义写**，blinear.m 边界带从逐像素比对中豁免。
7. **复用基准（LAT 已修正）**：bilinear_interp_8b 接口沿用 case1_calculate（u/v + 4 邻居 → 输出+valid），**valid 链用 `reg [LAT-1:0]` 移位寄存器，LAT=9**（case1 数据通路 9 级：原 L215-222 用 6 位寄存器取 [5] 延迟 7 拍、早 2 拍，本版修正为 9 拍对齐）；删除 case1 的 `_reg_copy` 冗余副本（L51-54）。
8. **FRAC_BITS 绑定**：W3 冻结 FB=8，核内位宽按 FB=8 实现（u/v=8、1-u=9、权重 18、乘积 26、和 27）；"FRAC_BITS 全参数化"标为后续 TODO，避免假参数化导致核位宽与坐标位宽失配。
9. **饱和/舍入（修正 case1 死代码）**：用 9 位中间量舍入后再饱和，防 8 位回绕：
   ```verilog
   wire [8:0] rounded = {1'b0, F_sum[23:16]} + {8'd0, F_sum[15]}; // 9位防回绕
   post_cal_data <= (rounded > 9'd255) ? 8'd255 : rounded[7:0];
   ```

## 实施步骤（含依赖）

**Step 0 — 目录与文档骨架 + AGENTS.md 修订登记**（无依赖）
- 在本目录建 README.md 骨架：架构图、公式、坐标系约定、已知限制（ROM 容量随 IN 尺寸增长，大图/视频流升级路径 = 行缓存方案）。
- **向 AGENTS.md"计划修订记录"追加**：W3 缩放判定不复用 line_buffer_nxn（光栅顺序窗口 vs 任意源坐标随机取邻域范式不匹配），改用整图 ROM+坐标寻址；行缓存复用保留给 W4 卷积。并把 AGENTS.md L73"W3/W4 缩放与卷积应复用"改为"W4 卷积应复用（W3 缩放已判定不复用，见修订记录）"。

**Step 1 — coord_gen.v**（无依赖，可最先做）
- 保留 v2 累加逻辑（L24-47）：`STEP_X = ((IN_WIDTH<<FB)+OUT_WIDTH/2)/OUT_WIDTH`；整数倍放大时 `OUT=IN×scale`，`STEP≈(1<<FB)/scale`。
- 输出增加 `valid_out`（逐拍）与 `done`（帧末）；`src_x_int/src_y_int` 位宽 = `$clog2(IN)+1`（防累加溢出到 IN）。
- **权重取低 FB 位**：`u_frac = x_accum[FB-1:0]`（修正 v2 取高 8 位丢精度）。
- 端口：`clk/rst_n/start/pixel_en → src_x_int/src_y_int/u_frac/v_frac/valid_out/done`。

**Step 2 — bilinear_interp_8b.v**（依赖 Step 1 的 FB 约定）
- 接口沿用 case1：`clk/rst_n/u_frac/v_frac/pix_tl/pix_tr/pix_bl/pix_br/valid_in → pix_out/valid_out`。
- 9 级流水：①输入寄存 ②1-u/1-v（FB+1 位 `{1'b0,~u}+1`）③权重乘法输入寄存 ④4×权重乘法（2FB+2 位）⑤像素对齐寄存 ⑥4×权重×像素（2FB+10 位）⑦乘积寄存→两项和 ⑧四项和（2FB+11 位）⑨右移 2FB+舍入+饱和。
- **valid 链 `reg [LAT-1:0]`，LAT=9**；删除 case1 `_reg_copy` 冗余副本。
- **饱和用 9 位防回绕写法**（见决策 9）。
- 遵循工程复位铁律：流水寄存器异步复位，无 BRAM。

**Step 3 — image_rom.v**（无依赖）
- `localparam DEPTH = IN_WIDTH*IN_HEIGHT; localparam ADDR_W = $clog2(DEPTH);`
- `(* ram_style="block" *)` reg [23:0] mem [0:DEPTH-1]；`initial $readmemh(INIT_FILE, mem)`。
- 同步读（1 拍潜伏），读输出寄存器同步复位（守 BRAM 铁律）。

**Step 4 — bilinear_rgb_top.v**（依赖 Step 1/2/3，接口先冻结再集成）
```
coord_gen ─ src_x_int/src_y_int → 地址计算+钳位+权重清零 → 4×image_rom 并行读
         └ u_frac/v_frac/valid ─ 延迟对齐（ROM 读 1 拍）→ 3×bilinear_interp_8b
                                                        → o_r/o_g/o_b + o_valid
```
- **地址位宽防截断**：`addr = ADDR_W'(sy)*IN_WIDTH[ADDR_W-1:0] + ADDR_W'(sx)`（先扩展操作数再乘，避免 sy*IN_W 高位被截）。
- 邻居地址：`addr00 = sy*IN_W + sx`；`addr10 = addr00+1`；`addr01 = addr00+IN_W`；`addr11 = addr00+IN_W+1`；sx/sy 及 +1 钳位到 [0, IN_W-1]/[0, IN_H-1]，**被钳位方向权重清零**（决策 6）。
- 3 个核共用同一根 valid 链与同一 LAT=9，杜绝三通道错位。
- **预留流式 i_mode**（决策见下方 W4 衔接）：mode=0 走 ROM，mode=1 预留 din/din_valid 接口。
- **include 链**：`bilinear_rgb_top.v` 头部依次 `` `include `` coord_gen.v / bilinear_interp_8b.v / image_rom.v，保持"只编译 TB"惯例。
- 参数：`IN_WIDTH/IN_HEIGHT/SCALE/FRAC_BITS/INIT_FILE`（OUT 由 IN×SCALE 推出）。

**Step 5 — make_tb_input.py**（无依赖，可并行）
- 读 MATLAB 生成的 input.coe → 剥离两行 header、去逗号 → 写 input.hex（每行一个 24bit hex，R 最高字节）。
- 校验：加载像素数 == IN_W×IN_H，否则报错。
- 可选 `--synthetic HxW` 生成合成梯度图（供 Step 8）。

**Step 6 — tb_bilinear_rgb.v**（依赖 Step 4/5）
- 照工程 TB 铁律：头部 `` `include "bilinear_rgb_top.v" ``、`$dumpfile("tb_bilinear_rgb.vcd")` + `$dumpvars`、自检记分板、`[PASS]/[FAIL]` 结束、超时 `#N; $finish` 兜底。
- 激励：顶层参数 INIT_FILE 指向 input.hex。
- 自检：TB 内建定点参考模型（与 RTL 同坐标系同公式、**同钳位语义**），逐拍比对 RGB 三通道计错误。
- **输出**：o_valid 时 `$fwrite` 写 `output.coe`（两行 header + 每像素 `%02X%02X%02X,`，与 MATLAB 格式一致）。
- 运行：`iverilog -o tb.vvp tb_bilinear_rgb.v` → `vvp tb.vvp > sim_log.txt`。

**Step 7 — verify_scale.py**（依赖 Step 6 产出的 output.coe）
- **参考输入读 input.coe/input.hex**（与 $readmemh 进 ROM 的比特严格同源，纯文本零第三方依赖，避免 JPEG 解码差异）——不读 jpg 原图。
- OUT_W/OUT_H 由命令行参数传入（= IN×SCALE），并做 `像素数 == OUT_W×OUT_H` 校验。
- 计算 PSNR（W3 目标 >30dB）+ 最大误差 + PASS/FAIL 打印。
- **渲染**：output.coe → reshape(OUT_H,OUT_W,3) → 存 scaled.png + 与原图（input 侧）side-by-side 拼图，满足"显示放大后的图片进行对比"。渲染用标准库手写 BMP/PPM 或降级走 MATLAB fscanf，不让 PIL 进 PASS/FAIL 关键路径。
- 参考模型：独立实现与 RTL 同坐标系、同钳位语义的浮点双线性（对齐 blinear.m 内部公式，边界带豁免）。

**Step 8 — 小图端到端验证**（依赖 Step 6/7，2 倍优先）
- 合成 4×3 梯度图（pix = row*16+col）→ 8×6，覆盖边界/纯色/渐变。输入来源：`make_tb_input.py --synthetic 4x3` 或手写 12 行 input.coe 后走转换。
- 验收：TB 自检 0 错误 + Python PSNR 极高（小图理想值）。

**Step 9 — 真图闭环**（依赖 Step 8）
- **改 `matlab_img_coe_output.m` 两处路径**：输入指向 `bilinear_v1/matlab/test.bmp`（112×103，相对路径），输出指向本目录 input.coe；脚本约定"先 `imresize` 到 IN_H×IN_W 再导出"防尺寸失配。

**Step 10 — 整数倍缩放扩展验证**（依赖 Step 9）

## W4 衔接决策（流式接口预留）

W4 周五要"均值+高斯+CSC+缩放四模块串链路"，其余模块均为流式 `din/din_valid` 范式，而本版顶层默认走 ROM 随机读。为避免 W4 集成时重写，顶层预留 `i_mode`：
- **mode=0（本版验证用）**：内部 image_rom 随机读，坐标由 coord_gen 累加驱动。
- **mode=1（W4 预留）**：接 `din/din_valid`，内部例化 `line_buffer_nxn(N=2)` 行缓存，坐标由输入流计数器驱动——同时补上 W3"行缓存在缩放中复用"的学习目标。
- 若 W4 决定另起 `bilinear_v4` 行缓存版参与串链路，则本条降级为"v3 仅算法验证变体"，并把该决策同步进 Step 0 的 AGENTS.md 修订记录。二选一，实施 Step 4 时定死。

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 位宽截断（权重/乘积/和） | 按决策 4 一般式取位宽（FB=8：18/26/27 位），Step 2 严格对齐 |
| valid 链与流水级数错位 | Step 2 用 LAT=9 移位寄存器（对齐 9 级数据通路）；Step 6 TB 自检暴露错位 |
| 舍入 +1 回绕 / 饱和死代码 | Step 2 用 9 位防回绕写法（决策 9） |
| coord_gen 累加溢出（末像素 src_int 达 IN） | src_int 位宽 = clog2(IN)+1；钳位是**功能必需**（STEP 四舍五入使末像素可达 IN），Step 4 钳位兜底，Step 8 边界用例覆盖 |
| sy*IN_W 地址截断 | 操作数先扩展到 ADDR_W 再乘（Step 4） |
| COE 逗号/header 与 $readmemh 不兼容 | Step 5 唯一桥接脚本；Step 6 先小文件验证加载像素数 |
| 字节序错误（R 高字节 vs 低字节） | 全程固定 R=bit[23:16]；TB 写 COE 与 MATLAB 脚本同格式；verify 双端同一约定 |
| 三通道错位 | 3 核共用同一 LAT=9 / 同一根 valid 驱动链 |
| 参考与 RTL 坐标系/边界不一致 | 统一无中心对齐简单映射 + 同钳位语义；blinear.m 边界带豁免；PSNR 参考读 input.coe 同源 |
| 图片尺寸与写死参数失配 | matlab 脚本约定先 imresize 到 IN_H×IN_W；make_tb_input.py 行数校验兜底（失配时仿真不报错，只能靠校验拦截） |
| ROM 方案不扩展大图 | README 记录：BRAM 随 IN 尺寸线性增长，大图/视频流升级路径 = 行缓存方案（W4 后） |

## 被否决的替代方案

1. **复用 line_buffer_nxn(N=2) 做行缓存（本版数据通路）**：否决——该模块光栅顺序读、窗口锚定当前输入像素，与"任意源坐标取 2×2 邻域"范式不匹配；行缓存复用保留给 W4（见 W4 衔接决策），并已登记 AGENTS.md 修订记录。
2. **本版同时做非整数倍缩放**：否决（范围收敛）——整数倍缩放（放大 N/1、缩小 1/N）已覆盖 W3 学习目标（权重计算、行列衔接、定点化、跳读）；非整数倍（N/M 比例）参数化天然支持但未专项验证，留待后续。
3. **原样复用 case1 不改（含 valid 链/饱和/舍入坑）**：否决——三处均为照抄必错的硬伤，修正成本极低。
4. **24bit 单核一次算三通道**（case3_51cto 写法）：否决——3 个独立 8bit 核每个可独立验证、接口与 case1 对齐，学习可读性优先；权重共享省乘法器留作后续优化。
5. **中心对齐坐标系（srcX=(dstX+0.5)*ratio-0.5）**：否决——与现有 blinear.m/coord_gen 不一致，会破坏逐像素比对可验证性；作为 README 后续优化项记录。
6. **verify_scale.py 读 jpg 原图作参考**：否决——MATLAB 与 PIL 的 JPEG 解码可能 ±1，PSNR 被钉假上限，且引入第三方依赖；改读 input.coe 同源。
