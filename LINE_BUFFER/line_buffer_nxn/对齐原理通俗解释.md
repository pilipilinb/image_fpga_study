块6窗口位移解释
3x3窗口：

// 行0 (i=0)
j=0: win_flat_reg[0] <= win_flat_reg[1]   // 列0 ← 列1
j=1: win_flat_reg[1] <= win_flat_reg[2]   // 列1 ← 列2
j=2: win_flat_reg[2] <= win_col[0]        // 列2 ← 新列（块5组装的第0行数据）

// 行1 (i=1)
j=0: win_flat_reg[3] <= win_flat_reg[4]   // 列0 ← 列1
j=1: win_flat_reg[4] <= win_flat_reg[5]   // 列1 ← 列2
j=2: win_flat_reg[5] <= win_col[1]        // 列2 ← 新列

// 行2 (i=2)
j=0: win_flat_reg[6] <= win_flat_reg[7]   // 列0 ← 列1
j=1: win_flat_reg[7] <= win_flat_reg[8]   // 列1 ← 列2
j=2: win_flat_reg[8] <= win_col[2]        // 列2 ← 新列


呈现为：每过一个周期则窗口往左移一列
{w11，w12，win_col[0] }
{w21，w22，win_col[1] }
{w31，w32，win_col[2] }
