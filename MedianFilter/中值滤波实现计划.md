# 中值滤波实现计划（MedianFilter，W4 非线性滤波站）

## 背景与目标

W4 计划（fpga-image-month1-plan.md）周六预告："非线性滤波：理解中值滤波的排序网络原理"。前两站（MeanFilter 均值、GaussianFilter 高斯）均为线性滤波（加权平均）；**中值滤波是非线性**——窗口 9 像素**排序取第 5 个**（中值），对**椒盐噪声（脉冲噪声）碾压级有效**：极值点被直接剔除，而均值/高斯会把椒盐"抹开"成灰斑。本站学习核心：**排序网络**（找中值 ≠ 全排序）与椒盐去噪实验。

## 关键决策（用户已确认）

1. **排序网络 = 行排序三部曲**（**19 比较器**，用户校正版，经典教科书结构，面试必会画）：
```
① 每行 3 像素排序（3 比较器/行 ×3 = 9）→ r_max, r_mid, r_min
② 提取 3 候选（7 比较器）：
   cand1 = max(r0_min, r1_min, r2_min)   ← 行最小值中的最大值（2 比较）
   cand2 = mid(r0_mid, r1_mid, r2_mid)   ← 行中间值的中间值（3 比较）
   cand3 = min(r0_max, r1_max, r2_max)   ← 行最大值中的最小值（2 比较）
③ 中值 = mid(cand1, cand2, cand3)（3 比较器）
```
   正确性：行排序后三列候选恰好"夹住"全局中值，三者取中即第 5 大。
   **审查修正（重要，含反例）**：初版曾错误简化为 "B = 中间行的 mid（16 比较器）"，反例推翻——
   窗口 {{5,2,8},{4,9,1},{7,3,6}} 行排序后：min 列 {2,1,3}、mid 列 {5,4,6}、max 列 {8,9,7}；
   真中值 5；中行 mid=4 与候选组合 mid(3,4,7)=4 ❌；三行 mid 中值=5 得 mid(3,5,7)=5 ✅。
   三行 mid 的中值（3 比较器）不可省——16 比较器版本不正确，19 比较器是正确形态。
2. **RGB888 三通道并行**：1×line_buffer(DW=24) + 3×median_3x3_8b，与 Mean/Gaussian 架构一致
3. **椒盐噪声为主 + 高斯对照**：给 noise_add.py 加椒盐模式（--salt 概率参数，默认 10%）；对比实验同时跑椒盐图（中值主场）与高斯图（对照组，预期中值效果一般——如实展示，这是知识点）
4. 行缓存：line_buffer_3x3.v（crop 版，**已复制在 MedianFilter/，零改动**）

## 中值滤波原理（README 重点）

- **非线性**：输出不满足叠加性（均值/高斯是线性的），对脉冲噪声（椒盐）最优——窗口内若椒盐极值点少于 5 个，中值必为真实像素
- **与均值/高斯对比三句话**：椒盐噪声 → 中值完胜；高斯噪声 → 中值一般（排序丢弃信息，不如加权平均）；保边缘 → 中值不模糊边缘（线性滤波的共性弱点）
- **找中值 ≠ 全排序**：9 输入全排序要几十个比较器，中值只要 19 个（行排序三部曲）——"只需要第 5 个顺序统计量"的信息论直觉

## 位宽与资源

```
每像素 8bit：比较器全部 8bit（无加法/乘法）
排序网络：19 比较器/核，纯组合 + 2~3 级寄存器
流水：级1 三行排序（每行 3 比较器交换网络）→ 级2 列提取(A/B/C) + 三数取中 → 级3 输出寄存
valid 链 LAT 与级数严格一致（工程铁律：级数-LAT 一一对应）
```

| 用例 | 输入 | 验收 |

| 真图 112×103 | input.hex | TB PASS（排序网络 vs 全排序参考全等） |

| **椒盐去噪（主场）** | noise_add.py --salt 生成 | 中值 vs 均值/高斯三对比：中值 PSNR 大幅领先（预期 25+dB vs 15-18dB） |
| 高斯去噪（对照） | noise.hex（同份） | 如实展示中值效果一般（预期接近或低于均值），写入 README 知识点 |

命令流程，示例：
```powershell
iverilog -I . -o tb.vvp tb_median_filter.v; vvp tb.vvp > sim_log.txt
python noise_add.py --salt 0.10                     # 椒盐噪声图
iverilog -DSALT -I . -o tb_s.vvp tb_median_filter.v; vvp tb_s.vvp > sim_salt.txt

```

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 行排序三部曲实现错误 | TB 参考模型用 9 输入全排序取第 5（不同源），全等比对暴露任何交换错误 |
| 排序网络相等值处理 | 比较器统一 `<=`/`>=` 稳定写法；纯色帧用例覆盖 |
| 流水级数与 LAT 错位（前站教训） | 级数显式写死并与 valid 链 LAT 一一对应，头部注释明示 |
| 椒盐概率不当（>50% 窗口多数是椒盐） | 默认 10% 并文档说明上限；去噪实验固定概率保证可比 |
| 椒盐 PSNR 对比不可比（噪底不同） | 椒盐图用固定 seed 或直接存文件（同 Mean/Gaussian 的 noise.hex 契约）；高斯对照沿用同份 noise.hex |

## 被否决的替代方案

1. **9 输入全排序网络（Batcher odd-even merge）**：几十个比较器，找第 5 大用不着全排序；行排序三部曲是经典最优教学结构
2. **冒泡式逐趟淘汰**：思路直白但比较器更多、流水更深，且面试讲点差
3. **仅高斯去噪实验**：中值对高斯效果一般，说服力弱；椒盐才是主场，两者同场对比才有知识点
4. **pad 版行缓存**：与 Mean/Gaussian 一致用 crop 版（W1 pad 版本已在 MeanFilter 演示过变体做法，需要时照搬）
