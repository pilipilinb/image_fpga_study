## 项目简介

CSC（Color Space Conversion）将 RGB 像素流逐点转换为 YCbCr 色彩空间。它是视频处理链路中最基础的模块之一：

- **Y**：亮度分量（luma），保留大部分人眼敏感的信息
- **Cb / Cr**：蓝色差 / 红色差色度分量，可下采样压缩带宽（4:2:2 / 4:2:0）

**关键认知**：CSC 属于**逐像素点运算**（point operation，1 对 1 映射），数学上**不需要行缓存**——这与 W1 的邻域运算（卷积/缩放，需 N×N 窗口）形成对比，也是后续 W3/W4 理解"行缓存复用边界"的基础。

### 特性

- 完全手写 Verilog，不依赖 Xilinx Video Process Subsystem IP
- 三种 RTL 实现变体：**乘法器流水线版 / 参数化自测版 / 移位代替乘法版**
- MATLAB 浮点参考脚本 + 独立 Python 校验脚本（非 TB 自证，第三方算法重算比对）
- TB 内建自校验记分板：数据校验 + 同步对齐校验 + 复位检查三项全覆盖
- 负值处理、四舍五入、饱和限幅等定点化细节全部显式实现

## 算法原理

### BT.601 转换公式

ITU-R BT.601 标准（8-bit，色度带 +128 偏移）：

```
Y  =  0.299*R + 0.587*G + 0.114*B
Cb = -0.1687*R - 0.3313*G + 0.5*B    + 128
Cr =  0.5*R   - 0.4187*G - 0.0813*B  + 128
```

**注意**：本项目 `3stage` 系列采用的是网络博主的近似公式（系数和 < 1.0，见[已知问题](#已知问题与注意事项)），并非标准 BT.601；`shift_v` 与 `matlab` 版采用标准 BT.601 系数。

### 浮点 → 定点化

FPGA 无浮点单元，需将浮点系数放大为整数、运算后右移还原：

| 变体 | 定点化系数 | 放大倍数 | 还原 |
|---|---|---|---|
| `3stage` / `3stage_selftest` | `47/157/16`、`26/86(87)/112`、`112/102/10` | ×256 | 右移 8 位 |
| `shift_v` | `306/601/117`、`176/347/523`、`523/438/85` | ×1024 | 右移 10 位 |

定点化示例（3stage）：

```
Y  = (47*R + 157*G + 16*B + 4096) >> 8
Cb = (112*B + 32768 - 26*R - 86*G) >> 8
Cr = (112*R + 32768 - 102*G - 10*B) >> 8
```

四舍五入：`(v >> 8) + ((v >> 7) & 1)`，即取被舍弃的最高位（原结果 bit7）加到结果上。

### 负数处理与饱和限幅

- **负数处理**：不做有符号运算，而是**正数项、负数项分开累加**，最后比较大小、大减小——避免补码运算的符号麻烦，且天然防溢出
- **饱和限幅**：结果钳位到 `0 ~ 255` 无符号范围，防止越界回卷

### 3stage（乘法器版，主版本）

`rgb_to_ycbcr_3stage.v`，来源 CSDN 博主 + 小梅哥《FPGA系统设计与验证实战指南》。

四级数据流水线 + 同步信号 4 拍延迟链对齐：

```
输入 RGB ──► ① 乘法（9 个并行乘法）──► ② 加法（正负分开）──► ③ 求和/符号判断
        ──► ④ 截取+四舍五入 ──► 饱和限幅 ──► 输出 Y/Cb/Cr
```

设计要点：

- **异步复位同步释放**：外部 `i_rst_n` 低有效异步复位，内部两级同步器同步释放沿，避免复位释放亚稳态
- **同步信号打拍对齐**：`i_h_sync / i_v_sync / i_data_en` 打 4 拍与数据路径对齐，保证输出时序与像素流同步
- **负值处理**：Cb/Cr 正数项（色度项 + 128 偏移）与负数项（R/G 项）分开相加，比较大小后大减小，结果为负则钳 0

### 3stage_selftest（参数化自测版）

`rgb20yuv3stage.v`，同算法自测版，两处改进：

- 系数参数化命名（`Y_R_stone`、`Cb_G_stone` 等），可读性更好
- **TB 期望值通过层次引用 `dut.*` 直接取 DUT 参数**，避免期望算法与 RTL 硬编码不一致（如 Cb_G 系数：`0.338×256=86.53`，本版四舍五入取 87，主版截断取 86）

### shift_v（移位代替乘法版）

`rgb_to_ycbcr_shift.v`，来源 CSDN，完全不用乘法器，6 级流水线。

系数拆解为移位和，例如：

```
306 = 256 + 32 + 16 + 2  →  R×306 = (R<<8) + (R<<5) + (R<<4) + (R<<1)
601 = 512 + 64 + 16 + 8 + 1
```

对比价值：移位版本在缺少 DSP48 的小型器件上更省资源，但流水线更深、代码量更大；两版可对比"乘法器 vs 移位"的资源/时序权衡。

### matlab（浮点参考实现）

`rgb2ycbcr_matlab.m`：

- 标准 BT.601 矩阵的 RGB→YCbCr 正变换 + 逆变换验证（正反变换后图像应与原图一致）
- 末尾仿真 FPGA 定点化精度：浮点 vs 定点误差数值输出

## 快速开始

### 环境要求

- [Icarus Verilog](http://iverilog.icarus.com/)（`iverilog` + `vvp`）
- Python 3（仅 `3stage/verify_csc.py` 需要）
- GTKWave（可选，查看波形）

### 编译与仿真

以 `3stage` 为例（其余变体同理）：

```powershell
# 1. 编译（TB 头部已 `include "被测模块.v"`，只需编译 TB）
cd CSC/3stage
iverilog -o tb_rgb_to_ycbcr.vvp tb_rgb_to_ycbcr.v

# 2. 运行仿真（TB 自动生成 .vcd 波形，结束打印 PASS/FAIL）
vvp tb_rgb_to_ycbcr.vvp > sim_log.txt

# 3. 查看波形
gtkwave tb_rgb_to_ycbcr.vcd
```

### 独立校验（Python）

仅 `3stage` 提供独立校验脚本——解析 `sim_log.txt` 的 `RES|` 行，用**独立算法**重算期望值比对（不依赖 TB 内建参考模型），并输出定点 vs 浮点精度误差：

```powershell
python verify_csc.py
```

输出要点：

- 16 组测试向量逐组比对 PASS/FAIL
- 定点 vs 浮点最大误差（应 ≤ 1）
- 博主系数 vs 标准 BT.601 灰度对比（可见亮度压缩差异）

## 已知问题与注意事项

1. **3stage 系列使用"博主公式"而非标准 BT.601**：Y 系数和 `0.183+0.614+0.062 = 0.859 < 1.0`，灰度中性色亮度被压缩（如 `R=G=B=128 → Y=126`，标准 BT.601 应为 128）。`verify_csc.py` 末尾专门做了对比分析。若用于实际视频链路，建议改用 `shift_v` 或 `matlab` 的标准 BT.601 系数。
2. **Cb_G 系数不一致**：`3stage` 版取 86（`0.338×256=86.53` 截断），`3stage_selftest` 版取 87（四舍五入）。TB 期望必须与所测 DUT 参数一致——优先用层次引用 `dut.*` 取参数而非硬编码。
3. **`shift_v` 尚无 TB**：仅 RTL 源码，未接入仿真验证链路，后续可补。
4. **`3stage` 版 Cb/Cr 负值直接钳 0**：当色度结果理论上为负时截断为 0（而非按浮点真值钳位）。由于色度有 +128 偏移，实际有效像素不会触发，但在极端输入下与浮点参考存在边界差异。
