# CCM 色彩校正矩阵实现计划（M4-2，线性 RGB 域 10bit）

> 来源：`伪代码.c`（用户提供）+ M4 链路契约（线性 RGB 域 10bit，位宽缩减统一推迟到 Gamma 出口）。
> 本计划先**核对伪代码**，再给出定点化推导、架构决策与验证方案。

## 一、伪代码核对（结论：思路正确，5 处按本工程契约修正 + 1 处工业补强）

### ✅ 正确的部分

- 索引约定：`i` = 输出通道 = 矩阵**行**；`k` = 输入通道 = 矩阵**列**；`M[i][k]` = "输出通道 i 里输入通道 k 占多少份量" —— 与 RTL 一致
- 定点化：系数 ×2^FRAC 存整数（Q(整数位).12）；运行时 3 乘累加
- **先加舍入项、再右移、最后 clamp** —— 顺序正确（若先 clamp 后 round 会引入截断偏置）
- 示例矩阵本身合法：行和 = 1.00（中性色不变）、含负系数（通道解耦）、对角 > 1

### ⚠️ 需修正的 5 处

| # | 伪代码 | 问题 | 本实现 |
|---|---|---|---|
| 1 | `clamp(acc >>> FRAC, 0, 255)` | **8bit 输出与链路契约冲突**（线性 RGB 域全程 10bit，缩减在 Gamma 出口） | `clamp(..., 0, 1023)`，输出 3×10bit |
| 2 | `>>>` | Python 无 `>>>`（那是 Java/JS 无符号右移）；Verilog 里 `>>>` 是**算术**右移且需 `signed` | Python 用 `>>`（对负数即算术右移）；RTL 用 `>>>` + `signed` 声明 |
| 3 | 注释"acc 是标量（**25bit** 有符号）" | 25bit 是**按 8bit 输入**算的（3×8192×255≈2^22.9）；10bit 输入下通用上界 3×32768×1023≈**2^26.6** → 溢出 | **28bit 有符号**（上界证明见 §2.3） |
| 4 | `round(M[i][k] * (1<<FRAC))` | Python `round()` 是**银行家舍入**（`round(0.5)=0`、`round(2.5)=2`），与运行时 `+2^(F-1) 再 >>F`（round-half-up 向 +∞）**不自洽** | 系数用 `floor(x·2^F + 0.5)`，与运行时同规则 |
| 5 | （实施计划原文）"负系数钳 0" | 易误读为"把矩阵负系数改成 0"——那 CCM 就废了（**负系数正是通道解耦的本钱**） | 真实含义 = **结果钳 0**（clamp 下界），矩阵负系数原样保留 |

### ➕ 工业实践补强：行和精确为 1（灰阶严格保持）

round 后行和可能差 1 LSB（本题第 0 行 `7045−2540−410 = 4095 ≠ 4096`）→ 灰阶带 1/4096 固定偏色，
多级链上是**直流偏置**。做法：**残差补到对角项**（|系数| 最大 → 相对误差最小），行和精确 = 2^FRAC。

本题实测：第 0 行需要 +1（7045→7046），第 1/2 行天然精确。

**收益**：灰阶输入（r=g=b=v）⇒ acc = 4096v ⇒ `(4096v+2048)>>12 = v`，**逐位精确保持**（见 §4 灰阶保持判据）。

## 二、定点化推导（逐项，RTL 按此锁定）

### 2.1 系数（Q5.12 定点）

| 项 | 值 |
|---|---|
| FRAC | **12**（Q5.12；系数分辨率 1/4096 ≈ 0.024%，相对误差可忽略） |
| 系数位宽 MW | **16bit 有符号**（覆盖 |M| ≤ 8.0；本矩阵最大 1.72 → 7046） |
| 量化规则 | `M_int[i][k] = floor(M[i][k]·2^12 + 0.5)` + 行和残差补对角 |
| 本矩阵定点值 | `[[7046,-2540,-410],[-983,5898,-819],[205,-2089,5980]]`（行和均为 4096） |

### 2.2 输入

- 输入 = 线性 RGB 10bit（0..1023），打包成 30bit `{r,g,b}`（r 在 `[29:20]`）——与 M3/降噪同格式
- 乘数扩成 **11bit 有符号**（`{1'b0, v}`）：10bit 无符号最大 1023 > 10bit 有符号最大 511，必须扩 1 位

### 2.3 累加器位宽（上界证明）

```
|C| ≤ 2^15（MW=16 有符号）
|C·v| ≤ 2^15 × 1023 = 33,521,664 < 2^25.0        → 乘积 26bit 有符号够；本实现取 PW=27 留余量
|acc| = |Σ_{k=0..2} C[i][k]·v_k| ≤ 3 × 2^15 × 1023 = 100,564,992 < 2^26.6
⇒ AW = 28bit 有符号（上界 2^27−1 = 134,217,727）✓ 无溢出
```

本矩阵实际 |acc| ≤ (7046+2540+410)×1023 = 10,225,908 ≈ 2^23.3，28bit 余量充足。

### 2.4 输出

```verilog
rnd = acc + 2^(FRAC-1)        // +2048，round-half-up（对负数同样成立：floor((acc+0.5LSB)/LSB)）
sh  = rnd >>> FRAC            // 算术右移（signed）
out = (sh < 0) ? 0 : (sh > 1023) ? 1023 : sh   // ★ 饱和必须做：负系数减法会出负值、对角>1 会超上限
```

**为什么饱和不可省**：`acc` 的取值范围远超 [0,1023]（既有 −100M 也有 +100M 的可能），
减法项让结果可能为负、增益项让它可能溢出 —— clamp 是 CCM 唯一的"兜底"，也是它能输出的合法值域。

## 三、架构与流水

```
in(30bit 简流) → ccm_core（逐像素，无行缓存）
                   │  T0 组合：9 个 16×11 有符号乘 + 3 组 3 项加树 → accR/G/B(28bit signed)
                   │  T1：acc 寄存                    （★ DSP→加树关键路径独立一拍）
                   │  T2：+2^11 round → >>>12 → clamp[0,1023]（组合）→ 输出寄存
                   ▼
out(30bit 简流，LAT = 2)
```

- **LAT = 2**：T0 组合乘加 → T1 寄存 acc → T2 舍入/移位/饱和 → 输出寄存。若时序宽松可压成 LAT=1（乘加+舍入+clamp 全组合后一次寄存），文档记为时序取舍点
- **无行缓存**：CCM 是逐像素点运算（1→1 映射），不需要邻域 → 不需要 `line_buffer_fifo_nxn`
- **资源**：9 个乘法器（16×11）→ 若综合到 DSP48，约 9 个 DSP（或按流水复用减少）；本模块是**全链唯一必须用乘法器/DSP 的一级**（面试点）
- **反压/冻结**：`run_en = !stall`（`stall = out_valid && !out_ready`）门控 T1/T2 两级寄存；冻结时输出保持

## 四、bypass 与降噪的差异（★ 本模块的设计对比点）

| | 降噪（M4-1） | **CCM（M4-2）** |
|---|---|---|
| 处理路径延迟 | 行缓存 `K·W+K` + 核 3 拍（**上万拍量级**） | 核 LAT=2 拍 |
| bypass 实现 | **必须排空点切换**（两路延迟差 W+1 像素，热切换必然错位） | **等延迟旁路**：旁路链打同样 2 拍 → 出口 mux |
| 切换时机 | 帧级配置，禁止热切换 | **可任意拍切换**（两路延迟严格相等，sof/eol 天然对齐） |
| 代价 | 需要排空握手流程 | 一条 2 拍寄存链 |

⇒ **结论：bypass 的实现方式由"处理路径延迟"决定**。逐像素级的模块（CCM/Gamma）用等延迟旁路即可；
含行缓存的模块（降噪/锐化）必须排空点切换。这是能讲清"架构边界"的一个对比点。

## 八、面试点清单

1. **CCM 干什么**：把 sensor 的光谱响应校正到标准色空间（3×3 满阵）；与白平衡的区别 —— **WB 是对角阵修色温，CCM 是满阵修串色**；且 WB 必须在 CCM **之前**（WB·CCM ≠ CCM·WB）
2. **为什么必须有负系数**：正对角阵只能做增益（= 白平衡），只有负的非对角项才能"扣除别的通道串进来的分量"——**负系数是 CCM 的标志**
3. **为什么必须饱和**：减法出负、增益溢出，clamp 是唯一兜底
4. **定点化**：Q5.12（1/4096 分辨率）；round-half-up（+2^11 后算术右移）；系数与运行时**同一套舍入规则**（避免 golden 与 RTL 不一致）
5. **行和 = 1 的工程意义**：保中性色；定点化后把残差补对角项 ⇒ 灰阶逐位严格保持（消直流偏置）
6. **全链唯一用 DSP 的一级**：预算是 9 个 16×11 乘法（可复用/分时）；其余模块靠移位加法
7. **bypass 两种实现的边界**：延迟差小 → 等延迟旁路（可取）；延迟差大（含行缓存）→ 排空点切换
