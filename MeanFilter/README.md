## 项目简介

每个输出像素 = 以它为中心的 3×3 窗口里 **9 个像素的平均值**，用于平滑/去噪（把突变拉平，对高斯噪声一类的随机噪声有效）。

工程要点：

- **9 路加法树**：均值滤波系数全 1/9，没有乘法——所谓"乘累加树"在这里就是纯加法树
- **除 9 定点化**：9 不是 2 的幂，用 `(sum×57 + 256) >> 9` 近似（实测误差 <1 LSB）
- **复用行缓存**：窗口生成与均值计算职责分离，行缓存零改动
- **双版本**：crop（少一圈）与 pad/replicate（全尺寸），各有适用场景

## 算法原理

### 均值公式

```
out = (w11 + w12 + w13 + w21 + w22 + w23 + w31 + w32 + w33) / 9
```

### 除以 9 的定点化

9 不是 2 的幂，不能直接右移。两种做法：

| 做法 | 实现 | 代价 |
|---|---|---|
| 直接除法 | `sum / 9` | 综合展开成大除法器，费资源 |
| **定点近似（本工程）** | `(sum×57 + 256) >> 9` | 纯乘加，可进 DSP48，误差 <1 LSB |

- `57/512 = 0.111328` ≈ 1/9 = 0.111111，相对误差 0.2%
- `+256` 是四舍五入（右移 9 位前加 2^8）
- **实测精度**：真图 11536 个窗口，浮点均值 vs 定点输出最大误差 **0.89 LSB**

### 位宽推导（实现前先算）

```
9 像素 → 级1：每行 3 像素和（3 个加法器，10bit，3×255=765 < 2^10）
      → 级2：3 行和相加（12bit，9×255=2295 < 2^12）
      → 级3：×57 + 256 舍入 >>9 + 饱和（18bit 中间量，max 255.998 → 255）
valid 链 LAT=3，与数据通路严格对齐
```

详见下方[面试要点](#面试要点)第 1 条——动手前先推每一级位宽，是 FPGA 数字信号处理的三大基本功之一。

## 架构设计

### 数据流（复用行缓存）

```
din[23:0]/din_valid ──► line_buffer_3x3(_pad)（DW=24，W1 复用，零改动）
                          │ 3×3 窗口 w11..w33（24bit）
                          ├─ R[23:16] → mean_3x3_8b（R 核）
                          ├─ G[15:8]  → mean_3x3_8b（G 核）
                          └─ B[7:0]   → mean_3x3_8b（B 核）
                          │ 同一 matrix_valid 驱动三核
                          ▼
                    o_r/o_g/o_b + o_valid
```

- 行缓存负责"窗口生成"（BRAM 存 2 行 + 移位），滤波核负责"计算"——**职责分离，各自可测**
- 均值核的 9 像素求和与位置无关（对称），所以 crop/pad 两版 w 映射完全一致

### crop 版 vs pad 版

| 维度 | crop 版（line_buffer_3x3） | pad 版（line_buffer_3x3_pad） |
|---|---|---|
| 输出尺寸 | (H-2)×(W-2)，边缘一圈缺失 | **H×W 全尺寸**（replicate 复制边缘） |
| 边缘像素 | 不滤波 | 边缘也被均值平滑 |
| 输入要求 | 任意（可有气泡） | **必须带 blanking**（h-blank≥1 拍、v-blank≥W+8 拍） |
| PSNR（σ=40 同噪声） | 22.14 dB（中心对齐） | **22.18 dB**（全尺寸直接比） |
| 适用 | 简单、无约束 | **多级滤波不缩水**、需全尺寸输出 |

**实测结论**：内部区域两版算法完全相同，差异只在边缘一圈——pad 版把边缘 3.7% 像素的噪声也抑制了（PSNR +0.04 dB），且输出与输入逐像素对应、对比更公平。**pad 版更好的根本价值是"输出完整、级联不缩水"**，而非 PSNR 数值。

| 指标 | crop 版 | pad 版 |
|---|---|---|
| 噪声图 vs 原图 | 17.56 dB | 17.56 dB |
| 滤波后 vs 原图 | **22.14 dB** | **22.18 dB** |
| PSNR 提升 | +4.58 dB | +4.62 dB |

对比图：[mean_filter_compare.png](mean_filter_compare.png)（crop，左=原图|中=噪声|右=滤波后）、[mean_filter_compare_pad.png](mean_filter_compare_pad.png)（pad 版）。

## 面试要点

### 1. 动手写代码之前，先把每一级的位宽算出来

实现前按"最坏情况"推位宽：8bit×3=765→10bit；9 求和=2295→12bit；×57=130815→18bit；输出饱和防御。位宽对了流水线一次写对；错了静默截断丢数据、仿真还不一定报错，只能靠逐像素比对抓。

**面试表述**："我写滤波/卷积前会先把每一级的最坏位宽推出来——位宽对了流水线一次写对，错了就静默截断，只能靠 TB 逐像素比对暴露。"

### 2. 非 2 幂除数的定点化（除 9）

**面试表述**："除 9 这类非 2 幂除数，用定点近似 ×57>>9，误差 0.2%、实测不到 1 LSB——纯乘加不费除法器，和 W2 定点化一脉相承。"

### 3. 均值滤波没有乘法

"乘累加树"在均值滤波里只是 9 路加法树（系数全 1/9）；真乘累加留给高斯核（对称核 + pre-adder）。

### 4. crop vs pad 的取舍

**面试表述**："crop 简单但边缘少一圈，多级滤波会逐级缩水；pad 用 blanking 空拍补全尺寸、边缘 replicate，代价是输入必须带消隐——级联/全尺寸场景选 pad。"

## 使用方式

```powershell
# 1. 编译 + 仿真（iverilog，-I 指向本目录）
iverilog        -I . -o tb.vvp tb_mean_filter.v        # crop 版
iverilog        -I . -o tb_pad.vvp tb_mean_filter_pad.v  # pad 版
vvp tb.vvp > sim_log.txt

# 2. 高斯噪声去噪实验
python noise_add.py --sigma 40                       # 生成 noise.hex + 预览图
iverilog -DNOISE -I . -o tb_n.vvp tb_mean_filter.v   # 噪声图跑 crop 版
iverilog -DNOISE -I . -o tb_pad_n.vvp tb_mean_filter_pad.v
vvp tb_n.vvp > sim_noise.txt
python noise_add.py --compare --sigma 40             # crop 对比（中心对齐）
python noise_add.py --compare --full --out-coe output_pad.coe --sigma 40  # pad 对比（全尺寸）
```

## 已知限制与后续

- **除 9 为近似**（×57>>9）：误差 <1 LSB，视觉无感；要求精确到 0 误差需换除法器
- **pad 版依赖 blanking**：纯连续流（无空拍）需 2 倍速时钟或改 AXI-Stream 反压
- **下边缘为帧级处理**：适用于单帧处理；实时视频流需处理帧间衔接
- **已完成（W4 周二/周三前半）**：高斯滤波 [1 2 1; 2 4 2; 1 2 1] 已实现并验证（对称分组 + 移位，0 乘法器，去噪 22.50dB 优于本工程均值 22.14dB）→ 见 [GaussianFilter/README.md](../GaussianFilter/README.md)
- **已完成（W4 中值站）**：中值滤波已实现——椒盐场景碾压线性滤波（26.18dB vs 本工程 20.53dB），高斯场景略输（22.01 vs 22.14）→ 见 [MedianFilter/README.md](../MedianFilter/README.md)（同为 crop 版，含椒盐同噪底对比数据）
